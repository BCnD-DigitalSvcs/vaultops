# VaultOps: Project Brief

**One line:** Version control for your notes, as an Obsidian plugin.

## Who it's for
People who would like more control and involvement in their notes/vault;

## The problem
Github style version control and operation for those familiar with the workflow. The problem that I run into is that I take a lot of short notes and lose track of them. This tool keeps me more involved in my notes and clutter and forces me to deal with it in some way. If you lose notes, forget what you did, need to revert a change that was made, see what date you may have changed something, monitor project management, issues, tasks, calendars, all in one spot.

## v0.1.0 scope (desktop only)
- Sidebar panel (ribbon icon, command, status bar)
- Pending changes list with line counts and a diff view
- Commit one file, selected files, or all
- Discard, stash, and add-to-.gitignore actions
- Push, pull (fast-forward only), and fetch, with confirmations
- Commit history timeline and undo last commit
- Settings: repo folder, git path
- A "Dashboard" button in the sidebar that does nothing yet

## Out of scope for v0.1.0
- Kanban and boards
- The dashboard view itself
- Mobile support
- calendar
- task management
- projects
- issues


## How we build it
One GitHub issue per feature, one branch and PR per issue, merged to `main`.
